BTRPA ESP32-S3 Firmware Loader

This static page uses ESP Web Tools to flash the ESP32-S3 firmware from a Chromium-based browser using Web Serial.

Web Serial is not available. Use current Chrome or Edge on desktop.

Usage

  1. Serve this directory with a local static server, for example python -m http.server 8000 from the web-loader directory.
  2. Open http://localhost:8000/ in Chrome or Edge.
  3. Connect the ESP32-S3 over USB and put it into download/bootloader mode if the board does not auto-reset.
  4. Click Connect and flash ESP32-S3, select the serial port, then follow the browser prompts.

Firmware layout

Offsets are derived from firmware/build/flasher_args.json:

  • 0x0: firmware/bootloader.bin
  • 0x8000: firmware/partition-table.bin
  • 0xf000: firmware/ota_data_initial.bin
  • 0x20000: firmware/btrpa_scan_firmware.bin
